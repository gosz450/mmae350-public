## Course Overview

This repository contains student-facing course materials for
**MMAE 350: Computational Mechanics**.

The course introduces computational methods used in mechanical and aerospace
engineering, with an emphasis on numerical solution of engineering governing
equations. Python and Jupyter notebooks are used throughout the course as
primary computational tools.

Topics include linear algebraic systems, nonlinear equations, finite-difference
methods, heat conduction, wave propagation, introductory finite element methods,
finite-volume methods, and computational fluid dynamics applications.

## Repository Organization

### Modules

The `modules/` directory contains the core instructional materials for the course.

Each module may include:

- a `README.md` describing the topic and learning goals
- lecture slides
- companion Jupyter notebooks
- computational examples

For example:

```text
modules/
├── module00_setup/
├── module01_matrix_algebra/
├── module02_linear_systems/
└── ...
```

Additional modules will be released as the semester progresses.

---

### Homework

Homework assignments and supporting computational files will be added to the
`homework/` directory as they are assigned.

Homework submissions are made through **Canvas**, not through GitHub.

---

### Data

The `data/` directory contains shared input files used in demonstrations,
examples, and Jupyter notebooks.

### Software Setup and Tools

The `tools/` directory contains supporting files related to the Python
environment and other computational utilities used in the course.

Students should begin with **Module 00**, which provides instructions for
installing Python, creating the course virtual environment, and configuring
Jupyter.

## How Students Should Use This Repository

1. Clone or download the repository to your computer.
2. Complete **Module 00** to configure your computational environment.
3. As each module is released:
   - read the module README
   - review the lecture slides
   - work through the companion notebooks and computational examples
4. Complete homework assignments as posted.
5. Submit all required work through Canvas.
